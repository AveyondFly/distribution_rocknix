## 简介

drastic_adv 版本支持通过 `layout.json` 文件自定义 NDS 双屏的显示位置、大小和布局方式。您可以：

- 自定义上屏和下屏的位置和尺寸
- 设置透明叠加模式，让下屏悬浮在上屏之上
- 配置背景图片美化界面
- 创建多个布局方案，在游戏中随时切换

---

## 文件位置

layout.json 文件需要放置在以下路径：

```
/storage/.config/drastic/resources/bg/[分辨率]/layout.json
```

其中 `[分辨率]` 是您设备的屏幕分辨率，例如：

| 设备分辨率 | 文件夹名称 |
|-----------|-----------|
| 1920×1080 | `1920x1080` |
| 1280×720  | `1280x720` |
| 640×480   | `640x480` |

**完整路径示例（1080p设备）：**
```
/storage/.config/drastic/resources/bg/1920x1080/layout.json
```

## layout.json 文件格式

### 基本结构

```json
{
  "name": "我的自定义布局",
  "layout": [
    {
      "index": 0,
      "type": 0,
      "name": "布局名称",
      "bg": "background.png",
      "rotate": 0,
      "screen0_x": 100,
      "screen0_y": 100,
      "screen0_w": 800,
      "screen0_h": 600,
      "screen1_x": 900,
      "screen1_y": 200,
      "screen1_w": 400,
      "screen1_h": 300
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | 字符串 | 否 | 整个布局配置的名称（显示用） |
| `layout` | 数组 | 是 | 包含多个布局方案的数组 |

**每个布局方案的字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `index` | 数字 | 是 | 布局索引，从0开始递增 |
| `type` | 数字 | 是 | 布局类型（0-4），详见下方说明 |
| `name` | 字符串 | 否 | 此布局的名称 |
| `bg` | 字符串 | 否 | 背景图片文件名（放在同目录下） |
| `rotate` | 数字 | 否 | 旋转角度：0=不旋转, 90=顺时针90°, 270=逆时针90° |
| `screen0_x` | 数字 | 是 | 上屏(Top Screen)的X坐标 |
| `screen0_y` | 数字 | 是 | 上屏的Y坐标 |
| `screen0_w` | 数字 | 是 | 上屏的宽度 |
| `screen0_h` | 数字 | 是 | 上屏的高度 |
| `screen1_x` | 数字 | 是 | 下屏(Bottom Screen)的X坐标 |
| `screen1_y` | 数字 | 是 | 下屏的Y坐标 |
| `screen1_w` | 数字 | 是 | 下屏的宽度 |
| `screen1_h` | 数字 | 是 | 下屏的高度 |

**坐标系说明：**
- 原点 (0, 0) 在屏幕左上角
- X轴向右为正
- Y轴向下为正

```
(0,0) ────────────────────► X轴
  │
  │    ┌─────────────┐
  │    │   screen0   │ (上屏/Top Screen)
  │    │   NDS上屏   │
  │    └─────────────┘
  │              ┌──────┐
  │              │scr1  │ (下屏/Bottom Screen)
  │              │下屏  │
  │              └──────┘
  ▼
 Y轴
```

## 布局类型详解

### type: 0 - 普通模式 (NORMAL)

标准的双屏布局，上屏和下屏并排显示（通常水平排列）。

**适用场景：** 大多数游戏的默认布局

**示例：**
```json
{
  "index": 0,
  "type": 0,
  "name": "普通模式",
  "screen0_x": 64,
  "screen0_y": 60,
  "screen0_w": 1280,
  "screen0_h": 960,
  "screen1_x": 1408,
  "screen1_y": 372,
  "screen1_w": 448,
  "screen1_h": 336
}
```

### type: 1 - 透明叠加模式 (TRANSPARENT)

**这是最强大的功能！** 上屏全屏显示，下屏以半透明小窗口的形式叠加在画面上。

**特殊功能：**
- 支持调节透明度 (Alpha)：让下屏窗口变得更透明或更不透明
- 支持调节位置 (Position)：下屏窗口可以放在四个角落（右上、左上、左下、右下）

**适用场景：** 
- RPG游戏（上屏看地图，下屏看状态）
- 需要大画面但偶尔看下屏的游戏

**示例：**
```json
{
  "index": 1,
  "type": 1,
  "name": "透明叠加",
  "screen0_x": 0,
  "screen0_y": 60,
  "screen0_w": 1280,
  "screen0_h": 960,
  "screen1_x": 1280,
  "screen1_y": 300,
  "screen1_w": 640,
  "screen1_h": 480
}
```

**注意：** 在透明模式下，`screen1` 的位置定义的是下屏的**初始大小**，实际显示位置由 Position 设置控制。

### type: 2 - 垂直模式 (VERTICAL)

双屏垂直排列，上屏在上，下屏在下。

**适用场景：** 竖屏游戏或特殊布局需求

**示例：**
```json
{
  "index": 2,
  "type": 2,
  "name": "垂直模式",
  "screen0_x": 600,
  "screen0_y": 0,
  "screen0_w": 720,
  "screen0_h": 540,
  "screen1_x": 600,
  "screen1_y": 540,
  "screen1_w": 720,
  "screen1_h": 540
}
```

### type: 3 - 高分辨率模式 (HIGHRES)

上屏全屏显示（保持4:3比例），下屏以小窗口形式放在旁边。

**适用场景：** 想要最大化上屏显示，同时保留下屏

**示例：**
```json
{
  "index": 3,
  "type": 3,
  "name": "上屏全屏",
  "screen0_x": 0,
  "screen0_y": 0,
  "screen0_w": 1440,
  "screen0_h": 1080,
  "screen1_x": 1440,
  "screen1_y": 360,
  "screen1_w": 480,
  "screen1_h": 360
}
```

### type: 4 - 单屏模式 (SINGLE)

只显示一个屏幕，完全隐藏另一个屏幕。系统会自动强制4:3等比例显示。

**适用场景：** 
- 只需要看上屏的游戏
- 追求最大画面的玩家

**示例：**
```json
{
  "index": 4,
  "type": 4,
  "name": "单屏模式",
  "screen0_x": 240,
  "screen0_y": 0,
  "screen0_w": 1440,
  "screen0_h": 1080,
  "screen1_x": 0,
  "screen1_y": 0,
  "screen1_w": 0,
  "screen1_h": 0
}
```

**注意：** 单屏模式下 `screen1` 可以设为全0。

## 如何创建自定义布局

### 步骤1：确定您的屏幕分辨率

首先需要知道您设备的屏幕分辨率。常见分辨率：

- 掌机常见：640×480, 854×480, 1280×720
- 高清设备：1920×1080

### 步骤2：计算屏幕位置

NDS 原生分辨率是 **256×192**（上下屏相同），宽高比为 **4:3**。

在设计布局时，建议保持4:3的宽高比以避免画面变形：

| 放大倍数 | 宽度 | 高度 |
|---------|------|------|
| 1x | 256 | 192 |
| 2x | 512 | 384 |
| 3x | 768 | 576 |
| 4x | 1024 | 768 |
| 5x | 1280 | 960 |
| 5.625x | 1440 | 1080 |

**计算居中位置的公式：**
```
screen_x = (屏幕宽度 - screen_w) / 2
screen_y = (屏幕高度 - screen_h) / 2
```

### 步骤3：创建 layout.json 文件

使用文本编辑器创建文件，注意：
- 文件必须是 **UTF-8 编码**
- 文件名必须是 **layout.json**（全小写）
- JSON 格式要正确（注意逗号和括号）

### 步骤4：放置文件

将 layout.json 放到正确的目录：
```
/storage/.config/drastic/resources/bg/[您的分辨率]/layout.json
```

### 步骤5：重启 drastic

重新启动 drastic 模拟器，新的布局配置就会生效。

## 主题和背景图片

### 背景图片设置

每个布局可以指定一个背景图片，用于美化界面。

**要求：**
- 图片格式：PNG 或 JPG
- 图片尺寸：与您的屏幕分辨率相同（如 1920×1080）
- 放置位置：与 layout.json 相同的目录

**示例：**
```json
{
  "index": 0,
  "type": 0,
  "name": "带背景的布局",
  "bg": "my_background.png",
  ...
}
```

### 多主题支持

drastic_adv 支持多套主题，每套主题可以有不同的背景图片。

**目录结构：**
```
/storage/.config/drastic/resources/bg/1920x1080/
├── layout.json
├── 1/                    ← 主题1
│   ├── background1.png
│   └── background2.png
├── 2/                    ← 主题2
│   ├── background1.png
│   └── background2.png
└── 3/                    ← 主题3
    └── ...
```

在 layout.json 中引用背景图片时，只需写文件名，系统会自动在当前主题目录中查找：
```json
"bg": "background1.png"
```

## 常见问题

### Q1: 布局没有生效怎么办？

**检查清单：**
1. 文件名是否正确？必须是 `layout.json`（全小写）
2. 文件路径是否正确？检查分辨率文件夹名称
3. JSON 格式是否正确？可以用在线 JSON 校验工具检查
4. 是否重启了 drastic？

### Q2: 画面变形了怎么办？

确保 screen 的宽高比接近 4:3（256:192）。如果画面被拉伸，调整 `screen_w` 和 `screen_h` 的比例。

### Q3: 透明模式下的下屏位置怎么调整？

透明模式 (type=1) 下，下屏的显示位置由游戏内的 Position 设置控制，不是由 layout.json 中的坐标控制。

在游戏中按 **Select+B** 打开设置菜单，选择 **Position** 可以切换下屏位置（右上→左上→左下→右下）。也可以直接按 **Select+R1** 快速切换。

### Q4: 如何调整透明度？

在游戏中按 **Select+B** 打开设置菜单，选择 **Alpha** 可以调整下屏的透明度。也可以直接按 **Select+L1** 快速调整。

### Q5: 如何切换布局？

在游戏中按 **Select+B** 打开设置菜单，选择 **Layout** 可以在多个布局之间切换。也可以直接按 **L2** 快速切换。

### Q6: 如何切换主题？

在游戏中按 **Select+B** 打开设置菜单，选择 **Theme** 可以在多个主题之间切换。也可以直接按 **Select+L2** 快速切换。

### Q7: 背景图片不显示？

**检查：**
1. 图片是否放在正确的主题目录下
2. 文件名是否与 layout.json 中的 `bg` 字段完全一致（区分大小写）
3. 图片格式是否支持（PNG 或 JPG）

## 快捷键参考

| 掌机按键 | 功能 |
|---------|------|
| Select+B | 打开/关闭设置菜单 |
| ↑/↓ | 菜单中选择选项 |
| ←/→ | 调整选项值 |
| B | 关闭菜单 |
| L2 | 快速切换布局 |
| Select+L2 | 快速切换主题 |
| Select+L1 | 快速调整透明度 |
| Select+R1 | 快速切换下屏位置 |

> **注意：** 像素滤镜切换功能需要通过设置菜单 (Select+B) 中的 Pixel 选项来调整。
