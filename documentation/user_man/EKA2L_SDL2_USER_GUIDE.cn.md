# EKA2L1 SDL2 使用说明

## 首次启动：安装固件

如果首次启动时没有检测到已安装的 Symbian 设备固件，程序会进入固件安装界面。

界面中需要选择两个文件：

- `ROM`：设备 ROM 文件。
- `RPKG`：设备固件包文件，通常以 `.rpkg` 结尾。

操作方式：

- `方向键`：在 `ROM`、`RPKG`、`Install`、`Exit` 之间移动。
- `Enter`：打开当前项目或确认。
- 在文件选择界面中，`Enter` 可进入文件夹或选择文件。
- 在文件选择界面中，`Left` 或 `Backspace` 返回上一级目录。
- `Esc`：返回或退出当前界面。

选择好 `ROM` 和 `RPKG` 后，`Install` 按钮会变为可用。按 `Enter` 开始安装。安装完成后会进入应用列表主界面。

## 应用列表主界面

启动后会显示已安装应用的图标列表。

主界面按键：

- `方向键`：移动选择框。
- `2 / 4 / 6 / 8`：也可以作为上、左、右、下导航使用，仅在主界面生效。
- `Enter`：启动当前选中的应用。
- `F1` 或 `F5`：打开 SIS/SISX 安装界面。
- `Space`：删除当前选中的应用。
- `Esc`：退出前端。

## 安装应用

在应用列表主界面按 `F1` 或 `F5` 打开应用安装界面。

操作方式：

- 选择 `SIS/SISX` 后按 `Enter`，进入文件选择界面。
- 选择 `.sis` 或 `.sisx` 文件。
- 回到安装界面后，选择 `Install` 并按 `Enter` 开始安装。
- 安装完成后，选择 `Exit` 或按 `Esc` 返回应用列表。

返回应用列表后，新安装的应用会自动刷新显示。

## 删除应用

在应用列表主界面，将光标移动到要删除的应用图标上，然后按 `Space`。

删除确认界面：

- 默认选中 `Cancel`，避免误删。
- `Left / Right`：在 `Delete` 和 `Cancel` 之间切换。
- `Enter` 或 `Space`：确认当前选择。
- `Esc`：取消删除。

选择 `Delete` 后，会卸载对应应用并删除其安装文件。内置在 ROM 中的系统应用不能删除。

## 游戏内按键

游戏运行时，主界面的 `2 / 4 / 6 / 8` 导航不会生效，它们仍然作为数字键输入。

默认游戏内按键：

- `方向键`：方向输入。
- `Enter`：确认 / 中键 / 选择。
- `F1`：左软键。
- `F2`：右软键。
- `F3`：绿色通话键。
- `F4`：红色挂机键。
- `Esc`：红色挂机 / 取消。
- `Backspace`：退格。
- `Space`：空格。
- `0` 到 `9`：数字键。

如果游戏内使用自己的退出选项退出，会返回应用列表主界面。

## 屏幕旋转

游戏运行时可调整显示旋转：

- `R`：每按一次顺时针旋转 90 度，循环顺序为 `0 -> 90 -> 180 -> 270 -> 0`。
- `F5`：打开屏幕旋转 OSD 菜单。

OSD 菜单按键：

- `Left / Right`：切换旋转角度。
- `Enter`、`Esc` 或 `F5`：关闭 OSD 菜单。

旋转后，方向键输入会跟随当前屏幕方向自动调整。
