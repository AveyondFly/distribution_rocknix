# J2ME 模拟器 — 玩家说明（中文）

英文版请参阅 [`J2ME_USER_MANUAL_en.md`](J2ME_USER_MANUAL_en.md)。

本说明介绍：**怎么用手柄玩游戏**、**怎么打开设置菜单**、**游戏设置保存在哪**、**想自己改键时该动哪个文件**。适合第一次使用的玩家阅读。

---

## 操作方式概览

- 游戏画面由模拟器运行，你用手柄控制；手柄会先被程序转换成「键盘信号」，再交给模拟器。
- 下面所有**手柄键名**（如 A、B、L1）以常见 Xbox 布局为准；**具体以你机器里自带的键位配置为准**（文件名一般为 **`j2me.gptk`**）。

---

## 组合键（Hotkey）

有些功能要 **先按住一颗「功能键」再按别的键**。这颗功能键在系统里叫 **Hotkey**（有的机器是 **Select**，有的是 **Back**，以你设备说明书或系统里 J2ME 启动说明为准）。

下文写的 **「Hotkey + A」** 表示：按住 Hotkey 不放，再按一下 A。

| 组合 | 作用 |
|------|------|
| Hotkey + A | 退出游戏（强制关闭模拟器） |
| Hotkey + B | 切换「机型按键布局」（多种品牌布局来回换） |
| Hotkey + X | 打开或关闭 **设置菜单**（分辨率、机型、旋转等） |
| Hotkey + Y | 打开或关闭 **指针模式**（用方向移动屏幕上的指针，**A** 当确认） |

---

## 游戏里的按键（不按 Hotkey）

| 对应手机上的键 | 手柄 |
|----------------|------|
| 左软键 | Back |
| 右软键 | Start |
| 确定 | A |
| 数字 0 | Y |
| 星号 * | B |
| 井号 # | X |
| 数字 1 / 3 | L1 / R1 |
| 数字 7 / 9 | L2 / R2 |
| 方向键 | 十字键，或左摇杆推方向 |

如果进游戏觉得「方向不对」「软键反了」，试 **Hotkey + B** 换布局，或在 **设置菜单** 里改 **Phone（机型）**。

---

## 菜单里的操作

先 **Hotkey + X** 打开设置菜单。打开时，按键会先控制菜单，不会进游戏。

| 操作 | 手柄 |
|------|------|
| 上下移动选项 | 十字键上/下，或左摇杆上/下 |
| 左右改当前选项的值 | 十字键左/右，或左摇杆左/右 |
| 关闭菜单 | 再按一次 **Hotkey + X**，或按 **Y** |

菜单里可以改：**分辨率**、**机型**、**旋转画面**。改完一般会马上生效，并会和游戏放在一起存成一个小配置文件，下次自动用（见下一节）。

---

## 其它快捷键（不按 Hotkey）

| 手柄 | 作用 |
|------|------|
| L3（左摇杆垂直往下按，视手柄而定） | 退出游戏 |
| R3（右摇杆垂直往下按，视手柄而定） | 截图 |

**旋转画面**：若默认键位没有单独分配，请在 **设置菜单** 里选 **Rotate** 调整。

## 游戏自己的设置保存在哪

- 和游戏 **同一个文件夹** 里，会有一个和游戏同名的 **`.conf` 文件**（扩展名就是 conf）。
- 里面会记住你在菜单里设的分辨率、机型、旋转等；**有这个文件时，会优先用里面的设置**。
- 第一次玩某个游戏若还没有这个文件，有的系统会根据**文件夹名字或文件名**里带的分辨率关键字自动猜一个（例如名字里带 `320x240`）。

## 想自己改键位（进阶）

1. 在机器里找到模拟器用的 **`j2me.gptk`**（常和模拟器启动脚本、java 配置在同一目录，具体路径因设备而异）。
2. **先复制备份**再改；改乱可随时拷回备份。
3. 文件里是「**手柄上的键 = 映射结果**」这样的行，带 **`_hk`** 的是 **按住 Hotkey 时** 的第二种功能。
4. 等号右边的写法**不能乱写**，需要符合你设备上 **`gptokeyb`** 程序支持的键名规则；不熟悉时可搜索 **gptokeyb 键位配置** 或看你设备开发商的说明。
5. 改完后一般需要 **重新启动游戏** 才生效。

若你**没有改过** `j2me.gptk`，也可以向懂行的朋友要一份「适配你机型的 `j2me.gptk`」整体替换。

## 常见问题

**问：组合键没反应？**  
答：先确认你机器上 **Hotkey 到底是哪颗键**（问客服、看论坛或设备 wiki）。

**问：这篇文章的按键和我机器上不一样？**  
答：多半是你设备里的 **`j2me.gptk` 被换过**；以你机器里实际文件为准，或按上一节自己改。

**问：进游戏没声音？**  
答：先检查系统音量；仍没有则可能是该游戏或当前固件环境的问题，可到对应设备社区求助。
