# MRP SDL2 用户指南

本文面向通过前端直接启动 MRP 文件的用户。前端会自动处理启动和转换流程，用户通常只需要关注字体文件和手柄键位。

## 运行资源文件

MRP 运行时工作目录是：

```text
/storage/roms/mrp/mythroad/
```

模拟器需要以下字体文件来显示中文：

| 文件 | 是否必需 | 说明 |
| --- | --- | --- |
| `/storage/roms/mrp/mythroad/system/gb16_mrpoid.uc2` | 是 | 主要中文点阵字体，缺失时可能导致文字不显示或字体加载失败。 |
| `/storage/roms/mrp/mythroad/system/fonts/font16.tsf` | 推荐 | Android 包中的兼容字体。如果有这个文件，建议一起保留。 |

`/storage/roms/mrp/mythroad/` 下还可能包含这些兼容资源：

| 目录或文件 | 说明 |
| --- | --- |
| `system/` | 系统资源目录，至少需要放置 `gb16_mrpoid.uc2`。 |
| `system/fonts/` | 兼容字体目录，可放置 `font16.tsf`。 |
| `plugins/` | 兼容插件目录。有些 MRP 或旧版运行环境可能会依赖这里的扩展文件；如果资源包里带有这个目录，建议原样保留。 |
| 其他游戏生成的目录或文件 | 部分 MRP 会在 `mythroad` 下写入配置、缓存或存档。除非明确知道用途，不建议手动删除。 |

## 手柄映射

手柄按键通过 `gptokeyb` 映射。当前使用的配置文件是：

```text
/storage/.config/mrp/mrp.gptk
```

| 手柄输入 | MRP 效果 |
| --- | --- |
| 十字键上 | 手机数字键 `2` |
| 十字键下 | 手机数字键 `8` |
| 十字键左 | 手机数字键 `4` |
| 十字键右 | 手机数字键 `6` |
| 左摇杆上 | 手机数字键 `2` |
| 左摇杆下 | 手机数字键 `8` |
| 左摇杆左 | 手机数字键 `4` |
| 左摇杆右 | 手机数字键 `6` |
| 右摇杆上 | 手机数字键 `2` |
| 右摇杆下 | 手机数字键 `8` |
| 右摇杆左 | 手机数字键 `4` |
| 右摇杆右 | 手机数字键 `6` |
| A | 手机数字键 `5` |
| B | 手机数字键 `0` |
| X | `*` |
| Y | `#` |
| L1 | 手机数字键 `1` |
| R1 | 手机数字键 `3` |
| L2 | 手机数字键 `7` |
| R2 | 手机数字键 `9` |
| L3 | 挂机键 |
| R3 | 拨号键 |
| Start | 左软键 |
| Back | 右软键 |
| Guide | 挂机键 |

## 组合键

| 组合输入 | MRP 效果 |
| --- | --- |
| Hotkey + A | 挂机键 |
| Hotkey + B | 拨号键 |
| Hotkey + X | 音量加 |
| Hotkey + Y | 音量减 |
| Hotkey + L1 | 音量加 |
| Hotkey + R1 | 音量减 |
| Hotkey + L2 | 确认 |
| Hotkey + R2 | 右软键或返回 |
| Hotkey + 十字键上 | MRP 方向上 |
| Hotkey + 十字键下 | MRP 方向下 |
| Hotkey + 十字键左 | MRP 方向左 |
| Hotkey + 十字键右 | MRP 方向右 |

## 修改键位

如果要修改手柄键位，编辑：

```text
/storage/.config/mrp/mrp.gptk
```

把手柄按键映射到对应的键盘按键即可。常用键盘输出如下：

| 键盘输出 | MRP 效果 |
| --- | --- |
| `0`-`9` | 手机数字键 `0`-`9` |
| `s`，兼容 `shift+8` | `*` |
| `d`，兼容 `shift+3` | `#` |
| `f1` | 左软键 |
| `f2` 或 `backspace` | 右软键或返回 |
| `f3` | 拨号键 |
| `f4` 或 `escape` | 挂机键 |
| `enter` 或 `space` | 确认 |
| `pageup` | 音量加 |
| `pagedown` | 音量减 |
| `m` | 打开/关闭 SDL OSD 菜单 |

修改 `mrp.gptk` 后，需要重启前端或模拟器会话，让新映射生效。

## 说明

- 普通十字键和摇杆方向有意映射为数字键 `2/4/6/8`，因为很多 MRP 游戏直接使用数字键作为方向键。
- OSD 菜单支持画面旋转和 `2468 -> DPad` 模式；上下选择项目，左右修改，`m`/Enter/Escape 关闭。
- 开启 `2468 -> DPad` 后，键盘 `2/4/6/8` 会转换为 `MR_KEY_UP/LEFT/RIGHT/DOWN`。
- A/B 映射为 `5/0`；X/Y 直接输入 `* / #`。
- 旧的 A/B 功能（`enter/backspace`）保留在 Hotkey + L2/R2。
